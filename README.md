# Ignoresirens

CLEO script that makes pedestrian cars ignore police sirens. Instead of panicking and swerving wildly, they just keep driving normally.

## Install

Drop the `Ignoresirens` folder into your `modloader` folder.

gta-san-andreas/
└── modloader/
└── Ignoresirens/
└── Ignoresirens.cs


No other configuration needed.
